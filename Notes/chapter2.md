# What is Node.js?

Node.js is a JavaScript runtime.

Normally, JavaScript runs only inside a browser.

Node.js allows JavaScript to run outside the browser, such as on your computer or server.

Without Node.js, you cannot use npm or create a React project with Vite.

---

# Why Do We Need Node.js?

Node.js helps us:

- Install packages
- Run development servers
- Build projects
- Execute JavaScript outside the browser

---

# What is npm?

npm stands for **Node Package Manager**.

It is installed automatically with Node.js.

npm is used to install packages (libraries).

Example:

```bash
npm install react
```

This downloads React into your project.

---

# What is npx?

`npx` executes packages without installing them globally.

Example:

```bash
npm create vite@latest
```

or

```bash
npx create-react-app my-app
```

It downloads the required package (if needed), runs it, and then exits.

---

# What is Vite?

Vite is a modern build tool used to create React applications quickly.

It provides:

- Fast project creation
- Fast development server
- Hot Module Replacement (HMR)
- Optimized production builds

---

# Why Vite Instead of Create React App?

| Vite | Create React App |
|------|------------------|
| Very fast | Slower startup |
| Instant refresh | Slower refresh |
| Modern tooling | Older configuration |
| Lightweight | Heavier setup |

Most new React projects use Vite.

---

# Creating a React Project

Run:

```bash
npm create vite@latest
```

Follow the prompts:

```text
Project Name:
my-react-app

Framework:
React

Variant:
JavaScript
```

Move into the project:

```bash
cd my-react-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

---

# What Happens After npm install?

`npm install` reads:

```
package.json
```

It downloads every required package and creates:

```
node_modules/
```

---

# Understanding package.json

`package.json` is the heart of your project.

It contains:

- Project name
- Version
- Scripts
- Dependencies

Example:

```json
{
  "name": "my-react-app",
  "version": "1.0.0",
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  }
}
```

---

# Understanding package-lock.json

This file locks the exact package versions.

Purpose:

- Ensures everyone installs the same versions.
- Makes builds consistent across different computers.

Normally, you do not edit this file manually.

---

# What is node_modules?

This folder contains all installed packages.

Example:

```
node_modules/

├── react
├── react-dom
├── vite
├── eslint
└── hundreds of dependencies
```

Important:

- It can be very large.
- Never edit files inside it.
- It is usually ignored by Git using `.gitignore`.

If deleted:

```bash
npm install
```

will recreate it.

---

# Project Structure

```
my-react-app/

├── node_modules/
├── public/
├── src/
├── index.html
├── package.json
├── package-lock.json
├── vite.config.js
└── .gitignore
```

---

# public Folder

Used for static files.

Examples:

- favicon
- images
- PDFs
- robots.txt

Files here are served directly.

---

# src Folder

This is where most of your React code lives.

Example:

```
src/

├── assets/
├── App.jsx
├── main.jsx
└── index.css
```

You'll spend most of your time in this folder.

---

# App.jsx

This is the main component of your application.

Example:

```jsx
function App() {
  return (
    <h1>Hello React</h1>
  );
}

export default App;
```

---

# main.jsx

This is the entry point of the application.

It connects React to the HTML page.

Example:

```jsx
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App";

ReactDOM.createRoot(document.getElementById("root")).render(
  <App />
);
```

---

# index.html

Unlike traditional websites, React has only one HTML page.

Inside it:

```html
<div id="root"></div>
```

React renders the entire application into this `<div>`.

---

# vite.config.js

This file contains Vite configuration.

Example:

```javascript
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";

export default defineConfig({
  plugins: [react()],
});
```

You usually don't need to change it as a beginner.

---

# Running the Development Server

Start the project:

```bash
npm run dev
```

This command starts Vite's development server.

Whenever you save a file:

- React recompiles
- Browser refreshes instantly
- Your state is often preserved using Hot Module Replacement (HMR)

---

# Build for Production

Create an optimized production build:

```bash
npm run build
```

This generates a `dist/` folder.

The `dist` folder contains files ready to deploy.

---

# Common npm Commands

Install dependencies:

```bash
npm install
```

Install a package:

```bash
npm install axios
```

Start development server:

```bash
npm run dev
```

Build project:

```bash

```

Preview production build:

```bash

```

---

# Behind the Scenes

When you run:

```bash
npm run dev
```

The flow is:

```
package.json

↓

Runs "vite"

↓

Vite starts development server

↓

Browser opens localhost

↓

React renders App.jsx

↓

App appears inside #root
```

# Interview Questions

### What is Node.js?

A JavaScript runtime that allows JavaScript to run outside the browser.

---

### What is npm?

A package manager used to install and manage project dependencies.

---

### What is Vite?

A fast build tool for modern web development.

---

### Why is Vite faster than Create React App?

Because it uses native ES modules during development and performs optimized builds.

---

### What is package.json?

It stores project information, dependencies, and scripts.

---

### What is node_modules?

A folder containing all installed packages and their dependencies.

---

### What is the purpose of main.jsx?

It renders the root React component into the HTML page.

---

### Why is there only one index.html?

Because React is a Single Page Application (SPA) and updates the UI dynamically.
